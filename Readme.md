| | Engine | What it does |
|:--:|:--|:--|
| 🪤 | **[EchoTrap](https://github.com/YAMRAJ13y/echotrap)** | Zero-click prompt-injection lab + the defense that stops it &nbsp;`OWASP LLM01` |
| 🛡️ | **[SkillSentry](https://github.com/YAMRAJ13y/skillsentry)** | Semantic scanner for malicious MCP servers & agent skills &nbsp;`OWASP Agentic` |
| 🛠️ | **[PatchPilot](https://github.com/YAMRAJ13y/patchpilot)** | Patch what's actually exploited — CISA KEV + FIRST EPSS over raw CVSS |
| ⚒️ | **[IOCForge](https://github.com/YAMRAJ13y/iocforge)** | One unified verdict from many free intel feeds — SOC IOC enrichment & triage |
| 🛂 | **[IdentityWatch](https://github.com/YAMRAJ13y/identitywatch)** | Detection-as-code for identity attacks (impossible travel, MFA fatigue) &nbsp;`MITRE ATT&CK` |
| 🥒 | **[PickleGuard](https://github.com/YAMRAJ13y/pickleguard)** | Statically detect malicious pickle opcodes in ML models — without unpickling them |
| 🔦 | **[LeakLens](https://github.com/YAMRAJ13y/leaklens)** | Ransomware leak-site OSINT — group/sector/country trend dashboards &nbsp;`CTI` |

<sub>All MIT-licensed, Python, with docs and tests.</sub>
